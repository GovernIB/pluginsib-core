# ![Logo](https://github.com/GovernIB/maven/raw/binaris/pluginsib/projectinfo_Attachments/icon.jpg) pluginsib-core-3.0
*Core de PluginsIB*

***Descripció***

Repositori que conté les classes comunes i d'utilitat de PluginsIB. No té cap dependència a cap llibrería de tercers.

IMPORTANT: Caracteristiques de PluginsIB Core 3.0:
* Està desenvolupada per treballar en JDK 11.
* Les classes s'han mogut del package org/fundaciobit/pluginsib/core a un altra package org/fundaciobit/pluginsib/core/v3, 
  cosa que llibreries amb versions 2.0.X puguin conviure amb la versió 3.0.
* De la versió v3 s'ha esborrat la classe CertificateUtils ja que usava classes internes del JDK.
